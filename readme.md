AGRO

AGRO is an AI-powered multilingual farming assistant designed to help farmers with crop recommendations, disease detection, weather insights, and agricultural guidance through a fast, mobile-friendly interface.

Features
Crop recommendation system
Plant disease scanning
Live weather updates
AI-powered farming assistant
Multilingual support
Mobile-first responsive design
Progressive Web App (PWA) support
Tech Stack
React
TanStack Start
TypeScript
Vite
Tailwind CSS
Supabase
React Query
Setup

Install dependencies:

npm install

Run development server:

npm run dev

Build for production:

npm run build

Preview production build:

npm run preview
Environment Variables

Create a .env file in the project root:

VITE_GROQ_API_KEY=
VITE_PLANT_ID_API_KEY=
VITE_OPENWEATHER_API_KEY=
PWA Support

AGRO can be installed as a Progressive Web App on supported mobile and desktop browsers.
